⚡ QUICK START (10 MINUTES):

  Step 1: Install Dependencies
    $ npm install
    $ cd frontend && npm install

  Step 2: Compile & Test
    $ npm run compile
    $ npm test

  Step 3: Deploy Locally
    Terminal 1: $ npm run node
    Terminal 2: $ npm run deploy:local
    Terminal 3: $ npm run dev

  Step 4: Open Browser
    → http://localhost:3000
    → Connect MetaMask
    → Create your first batch!
